
CiteVerify – Scientific Claim and Citation Verification System

AI-Powered Platform for Scientific Claim and Citation Verification

About the Project

CiteVerify is an AI-powered scientific verification system designed to check whether claims made in academic documents are genuinely supported by their cited research papers.

Students and researchers frequently use scientific references in assignments, reports and research documents. However, a citation may be incorrect, unrelated or may not fully support the statement.

CiteVerify aims to automate this verification process using AI, NLP and research paper retrieval.

Problem Statement

Manually verifying every scientific claim against its original research paper is time-consuming and difficult. Existing references may be incorrect, misleading, outdated or only partially supportive.

CiteVerify aims to solve this problem through automated claim extraction, citation detection and evidence-based verification.

Key Features

- Document & Claim Extraction: Extract scientific claims, statements and references from uploaded academic documents.
- Citation Detection: Identify citations such as [1], [2] and author-year references.
- Original Paper Retrieval: Retrieve research publications using DOI, title and author information.
- Citation Mapping: Connect extracted claims to their corresponding references.
- Evidence Comparison: Compare scientific claims with findings, scope and limitations in original research papers.
- Claim Classification: Categorize verification results.
- Misleading Reference Detection: Identify incorrect, unrelated or potentially outdated references.
- Evidence & Source Traceability: Display relevant evidence passages and source details.
- Verification Report: Generate an evidence-based report with verdicts and confidence indicators.

Verification Categories

1. SUPPORTED
2. PARTIALLY SUPPORTED
3. UNSUPPORTED
4. CONTRADICTORY
5. POSSIBLY OUTDATED

Each result aims to include an explanation and supporting source evidence.

Proposed System Workflow

1. Upload an academic document.
2. Extract scientific claims and citations.
3. Retrieve original research papers.
4. Map claims to references.
5. Compare claims with source evidence.
6. Classify verification results.
7. Generate a structured verification report.

Proposed Technology Stack

- Frontend: React and Tailwind CSS
- Backend: Python and FastAPI
- Document Processing: PyMuPDF
- AI/NLP: Natural Language Processing and Large Language Models
- Research Retrieval: Crossref and OpenAlex
- Semantic Comparison: Sentence Transformers
- Database: SQLite / PostgreSQL

The technology stack will be finalized based on the actual implementation.

Expected Output

For every verified claim, the system aims to provide:

- Extracted scientific claim
- Corresponding citation
- Original research paper details
- Relevant evidence passage
- Verification verdict
- Confidence indicator
- Source traceability

Project Goal

Our goal is to improve academic trust by making scientific claim verification faster, more transparent and evidence-based.
